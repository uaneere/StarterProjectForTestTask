# Тестовое задание: кружок бодяженья
Небольшая сцена варки зелий поверх стартового Unity-проекта: меню, комната мага, шкаф, стол, котёл и пауза.
## Механика и управление
Маг ходит по комнате и готовит зелье по случайному рецепту.
- **WASD / стрелки** — движение
- **E** — взаимодействие: открыть шкаф, положить/взять предмет со стола, начать обработку ингредиента у котла
- **ЛКМ по слоту шкафа** — взять или положить предмет
- **Стрелки во время QTE** — вести один из двух путей (разные эффекты). Общий префикс продвигает оба пути; ошибка по пути его отключает; промах по обоим или таймер — провал, применение случайного эффекта (шанс 1 к 4 нужного из общего списка всех возможных эффектов)
- **F** или кнопка «Завершить зелье» — сдать содержимое котла (только рядом с котлом). Верная последовательность даёт зелье в руки, неверная бьёт по здоровью
- **Esc** — пауза / закрыть шкаф / снять паузу
- **R** — новая попытка после смерти
На стол зелье можно поставить (в дальнейшем его можно использовать для связи с финансовой бизнес логикой игры, а так же в файлах спрайтов присутствуют нож и ступка для наложения эффектов или изменения ингредиентов, что в дальнейшем можно реализовать).
## Как запустить
1. Открыть проект `TestTaskProject` в Unity **6000.3.8f1**.
2. В Build Settings первой должна быть `Menu`. Play из редактора тоже стартует с неё.
3. **Играть** -> комната мага. **Выход** в меню из паузы. Повторить переход несколько раз: объекты и UI не должны копиться.
Проверки:
- меню <-> игра несколько раз подряд;
- QTE с двумя путями, таймером и провалом;
- верный и неверный рецепт;
- шкаф, стол, пауза, смерть и **R**.
## Архитектура
Существующий Core не заменён, а дополнен.
- **Сцены.** UI и геймплей шлют `LoadSceneEvent` / `QuitApplicationEvent`. `SceneLoader` подписан на `EventManager` и один вызывает `SceneManager`. Перед загрузкой UI снимается через `UIController.Clear(destroyImmediate: true)`.
- **Имена сцен.** `SceneNames.Game = Game` (там `CoreSceneInstaller` и геймплей). `SceneNames.Menu = Menu` (там `MenuSceneInstaller`).
- **Zenject.** `CoreProjectInstaller` — `EventManager`, `UIController`, `SceneLoader`, `ScreenCatalog`. Сцены: `MenuSceneInstaller` / `CoreSceneInstaller` для своего скоупа. `MenuSceneBootstrap` зависит от `ScreenCatalog`, чтобы меню открывалось после регистрации фабрик.
- **UI.** `ScreenView` / `ScreenController`, фабрики в `ScreenCatalog`, показ через `OpenScreenEvent`. Экраны: меню и пауза. HUD комнаты - отдельный runtime-UI, не экран каталога.
- **Геймплей.** Состояние в обычных классах (`Cabinet`, `Cauldron`, `QteSession`, `GameContent`), оркестрация в `GameWorld`. Связь с UI — события (`CabinetSlotClickedEvent`, `FinishPotionRequestedEvent`, `GamePauseChangedEvent`).
## Трудозатраты
Ориентир: **16–20 часов** (инфраструктура сцен и UI, механика варки/QTE, спрайты, правки жизненного цикла).

- Unity + VSC (для работы с кодом и редактирования сцен в реальном времени)
